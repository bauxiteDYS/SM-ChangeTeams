# SM-NT-ChangeTeams
Sourcemod plugin for Neotokyo to allow changing teams with a command and forcing players to teams for admins

Use the `!s`, `!j`, `!n`, commands to join Spectator, Jinrai and NSF teams respectively.  
Admins can use `!spec <target>` or `!sf <target>`, `!jf <target>` and `!nf <target>` to force a player to a Spectator, Jinrai or NSF team respectively, where `<target>` is a unique partial (or full) name or player userid, typed according to SM targetting rules.

# Building
## Requirements
* SourceMod 1.7 or newer
* [SourceMod Neotokyo include](https://github.com/softashell/sourcemod-nt-include)
