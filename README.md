# SM-Dys-ChangeTeams
Sourcemod plugin for Dystopia to allow changing teams with a command and forcing players to teams for admins

Use the `!s`, `!p`, `!c`, commands to join Spectator, Punk and Corps teams respectively.  
Admins can use `!spec <target>` or `!sf <target>`, `!pf <target>` and `!cf <target>` to force a player to a Spectator, Punk or Corps team respectively, where `<target>` is a unique partial (or full) name or player userid, typed according to SM targetting rules.
